# moodle — плагин массового зачисления `local_massenrol`

**Идея:** зачислять студентов на курсы Moodle пачкой, а не по одному — выбрать курс, вставить список (ФИО/логины, группы) в таблицу и одним действием записать всех.

Плагин типа `local` (расширение системы, не блок и не activity), ставится в `local/massenrol`.

## Что реализовано

Код плагина есть и покрывает основной сценарий:

| Файл | Роль |
|---|---|
| `massenrol/index.php` (32 КБ) | основной интерфейс: выбор курса, таблица студентов, пошаговое зачисление |
| `massenrol/lib.php` (30 КБ) | логика: разбор списка, поиск пользователей, запись на курс, роли |
| `massenrol/settings.php` | настройки плагина в админке |
| `massenrol/ajax.php`, `save_step.php`, `courses_list.php` | AJAX-обработчики и пошаговое сохранение |
| `massenrol/version.php` | метаданные плагина |
| `massenrol/lang/`, `jspreadsheet.*` | языковые строки и табличный редактор |

Версия из `version.php`: `2025022300`, release `0.1`, зрелость **ALPHA**, требует Moodle `2024100700` (4.5+).

## Установка

1. Скопировать папку `massenrol` в `local/` установки Moodle: `<moodle>/local/massenrol`.
2. Открыть админку Moodle → «Уведомления» → установить плагин.
3. Настройки — в «Администрирование → Плагины → Локальные плагины → Массовое зачисление».
